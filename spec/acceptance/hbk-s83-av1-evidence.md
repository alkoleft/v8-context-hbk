# S83-AV1: enumeration глобальных BSL-методов по `AvailabilityContext`

Этот документ фиксирует дополнительный неранжированный измеренный проход T183.
Он не выбирает кандидата, не меняет замороженные критерии допуска основного
эксперимента и не назначает zero-copy-артефакт каноническим. Решение остаётся за
пользователем.

## Поведенческая эквивалентность AV1

Для каждого возвращённого глобального BSL-метода transcript содержит полный
global/callable payload: логические ID, kind/domain/name/alias, упорядоченные
сигнатуры, параметры, requiredness, ссылки на типы, возвращаемые типы и
availability callable. Фильтр использует только availability глобального
факта. Числовые ID текущей сессии не сравниваются.

Все девять строк побайтно совпали с ordered transcript H0 во всех девяти
контекстах. В corpus имеется 500 глобальных BSL-методов; ровно один метод с
пустым availability включён во все результаты, а несовпадающие явно заданные
контексты исключены.

## Состояние решения

AV1 доказывает полную эквивалентность именно для filtered enumeration
глобальных BSL-методов по `AvailabilityContext` и показывает измеренные
компромиссы startup/first/steady enumeration/page faults/аллокаций. Он не
измеряет точечный lookup типов или методов типов и не заменяет соответствующие
таблицы основного workload T183.

`ranked = false`, `selection = pending-user-decision`. H0 остаётся SQL baseline,
C0 — контрольной строкой. Ни F0, ни A0, ни L1, ни I1, ни D1, ни P1, ни R1 не
назначены первым, рекомендованным или каноническим вариантом. Основной
owned-путь остаётся каноническим до явного решения пользователя и отдельного
долговечного архитектурного решения.
